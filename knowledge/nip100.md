# NIP-100: Lightning Network Escrow Events

This relay implements NIP-100 which defines event kinds and structure for Lightning Network escrow services.

## Implementation Notes

- Use modular approach with separate policy functions
- Validate events through RejectEvent hooks
- Consider using Router for escrow-specific functionality
- Test with real Lightning Network transactions

## Event Kinds

- 30400: Escrow Agent Registration
- 30401: Task Creation
- 30402: Task Acceptance
- 30403: Task Resolution

## Validation Rules

1. All events must include version field
2. Task deadlines cannot be more than 30 days in the future
3. Task resolutions must reference both task and acceptance events
4. Resolution status must be one of: settled, disputed, canceled
5. Escrow agent registrations must specify supported currencies and valid fee rates

## Example Usage

```go
// Example relay setup with NIP-100 support
relay := khatru.NewRelay()

// Add NIP-100 validation policies
relay.RejectEvent = append(relay.RejectEvent,
    policies.ValidateKind,
    policies.PreventFarFutureDeadlines,
)

// Add NIP-100 to supported NIPs
relay.Info.SupportedNIPs = append(relay.Info.SupportedNIPs, 100)
```
